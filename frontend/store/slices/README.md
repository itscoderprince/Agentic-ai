# 📁 Store Slices Reference

This folder contains the modular Zustand slices for the chat and conversation state.

## Slices in this directory:
- **`conversationSlice.js`**: Manages sidebar chat lists, selection, pinning, renaming, and deleting conversations with optimistic updates.
- **`messageSlice.js`**: Manages active message history, optimistic user turns, Server-Sent Events (SSE) token streaming via the Web Streams API, and dual MongoDB persistence.
